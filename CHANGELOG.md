
# Changelog

## [1.0.0] - 2026-11-14

### Ajouts
- Création du paquet Python sentiment-app.
- Ajout de la fonction de prédiction predict().
- Ajout de l'interface en ligne de commande sentiment.
- Intégration du modèle de classification de sentiment.
- Ajout des dépendances et de la configuration de construction du paquet.

### Limites connues
- Le modèle est entraîné sur un jeu de données limité.
- Les avis ambigus ou ironiques peuvent entraîner des erreurs.
- Le modèle est conçu pour analyser des avis en français.
